# Tài liệu Kỹ thuật Pulse

Chào mừng bạn đến với trung tâm tài liệu của **Pulse**, nền tảng nhắn tin tức thời (Instant Messaging) phân tán, tốc độ cao được xây dựng bằng ngôn ngữ Go.

---

## Danh mục tài liệu

- [Kiến trúc tổng quan (Architecture)](./architecture.md): Tìm hiểu chi tiết về kiến trúc Cell-based, CQRS, Event Sourcing với NATS JetStream và PostgreSQL 16.
- [Hướng dẫn khởi chạy nhanh (Quickstart)](./quickstart.md): Các bước khởi chạy Pulse trên máy cục bộ trong 5 phút và kiểm thử hệ thống.
- [Danh mục REST API](./api-reference.md): Danh sách các endpoint quản lý tài khoản, xác thực, tin nhắn, nhóm chat và danh sách bạn bè.
- [Giao thức WebSocket (Wire Protocol)](./websocket-protocol.md): Đặc tả định dạng nhị phân MsgPack, chu trình bắt tay kết nối và danh mục mã frame.
- [Hướng dẫn cấu hình (Configuration)](./configuration.md): Hướng dẫn thiết lập qua file YAML và biến môi trường (ENV).
- [Hướng dẫn đóng góp mã nguồn (Contributing)](./contributing.md): Quy chuẩn đóng góp code, phong cách viết mã và kiểm thử.
